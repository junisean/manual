# 매뉴얼 작업실

외부 AI API 키 없이 작동하는 매뉴얼 생성기입니다. React, Vite 기반이며 자료 읽기와 내보내기는 브라우저에서 실행됩니다.

## 실행

Node.js 22 이상에서:

```text
npm install
node scripts/prepare-assets.mjs
npm run dev
```

http://127.0.0.1:5178 에서 엽니다. 완성본은 `매뉴얼 작업실 실행.cmd`를 더블 클릭하면 실행됩니다. 실행 창을 닫으면 서버가 종료됩니다. 사이트 주소는 http://127.0.0.1:5180 입니다.

## 배포

```text
npm run build
```

`dist` 폴더 전체를 정적 웹 호스팅에 배포합니다. 생성기는 HTTP/HTTPS로 제공해야 합니다. 내보낸 매뉴얼 HTML은 별도로 더블 클릭해서 열 수 있습니다. iframe과 WebView에서는 스크립트 실행을 허용하면 체크 기능이 작동합니다. 저장소 권한이 없으면 현재 화면의 체크만 유지됩니다.

## 지원과 처리 방식

- JPG, PNG, WEBP, BMP: 로컬 Tesseract 한국어/영어 OCR. 손글씨는 인식률이 낮을 수 있어 모든 인식 항목에 확인 표시를 남깁니다.
- PDF: 페이지별 텍스트 추출. 글자가 거의 없는 페이지는 OCR로 읽습니다.
- DOCX: 본문, 표의 텍스트와 포함 이미지를 읽습니다. Word 내부 쪽 번호는 보존하지 않으므로 화면의 1쪽은 추출 단위를 뜻합니다. DOC, HWP, HEIC는 지원하지 않습니다.
- TXT, MD, CSV, 직접 입력: 원문 텍스트를 읽습니다. CSV는 표를 해석하지 않고 원문 행을 유지합니다.
- `# 제목`, `[제목]`, Word 제목 스타일을 카테고리로 사용합니다. 그 외에는 자료 이름으로 묶습니다. 번호와 원문 순서를 유지합니다. 참고/주의/조건/예외/금지로 시작하는 문장은 참고 항목으로 구분합니다.
- 문맥 추론, 손글씨 의미 해독, 상충하는 업무 지시의 자동 판단은 하지 않습니다. 편집 기능으로 확인하고 수정합니다. K-Humanizer는 제작 시 UI 문구에 적용했습니다. 사용자 원문을 자동으로 바꾸지 않습니다.
- 매뉴얼 항목 이동, 카테고리 편집, 체크, 확인 완료, 원문 추적, 이미지 포함, 현재 작업 자동 저장과 JSON 백업을 지원합니다.
- HTML: 독립 실행, 안전한 문자열 처리, 체크 저장. JPG: 긴 문서는 페이지별 이미지 ZIP. PDF: 한글 글꼴을 포함한 검색 가능한 텍스트. DOCX: 편집 가능한 문단과 제목, 체크 기호.

작업과 첨부 자료는 해당 브라우저의 IndexedDB에 저장됩니다. 자동 기기 동기화는 제공하지 않습니다. 초기 생성기 로드 후 자료 처리와 내보내기 중 외부 AI 서비스로 자료를 보내지 않습니다.

## 글꼴과 오픈소스

Noto Sans KR은 SIL Open Font License에 따라 사용합니다. 배포 글꼴은 `@expo-google-fonts/noto-sans-kr`에서 가져옵니다. OCR은 Tesseract.js와 한국어/영어 학습 데이터를 사용합니다. 각 npm 패키지의 라이선스는 설치된 패키지에 포함되어 있습니다.
